# PGSO Folder Tracker Logbook (VS Code)

## Run it
1. Extract this ZIP.
2. Open the `pgso_folder_tracker` folder in Visual Studio Code.
3. Open `index.html` in your browser, or install the **Live Server** extension and click **Go Live**.

## Features
- Dashboard layout based on the supplied sample
- Weekly dashboard report with activity counts and return rate
- Borrowed/Returned status filters and inline status updates
- Edit or move a logbook entry to Recently Deleted from its three-dot actions menu
- Restore entries or permanently delete them from Recently Deleted
- Add and edit logbook entries, including details and notes
- Start date and time, pagination
- Responsive layout for desktop/tablet/mobile

Entries are saved in this browser using local storage, so they remain after a reload on the same browser and device. Clearing browser data will remove them. Connect a backend (Firebase, Supabase, or your own API) to share entries across users and devices or add authentication/real reporting.
